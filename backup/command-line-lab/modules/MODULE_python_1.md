## Briefing

Welcome to the Python track. Python is an interpreted, high-level, general-purpose programming language. Its design philosophy emphasizes code readability.

In this first module, you will learn how to print text to the console, declare variables, and read user input.

## Mission

Create a Python script named `module1/python/main.py` that reads a line of input from standard input and prints it back with a greeting.

## Objectives

1. Create a script named `main.py` in the directory `module1/python/`
2. Run your script using `python3 main.py` at least once
3. The script should read user input and print it back to the console

## Getting Started

To read input from the console, use the built-in `input()` function:
```python
name = input("Enter your name: ")
print("Hello, " + name)
```

Run your code to test it:
```bash
python3 main.py
```
