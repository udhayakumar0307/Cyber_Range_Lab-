# Cryptography Lab — Cyber Range

Interactive Cryptography Learning Lab covering fundamental encoding schemes, hash functions, algorithm identification, hash calculators, and classical encryption/decryption techniques.

## Modules Covered
1. **Module 1: Cryptography Basics** — Encoding vs Encryption vs Hashing, Base64, Hexadecimal
2. **Module 2: Hash Basics** — MD5, SHA1, SHA256, hash comparisons, algorithm identification
3. **Module 3: Hash Calculator** — Interactive digest computation (MD5, SHA1, SHA224, SHA256, SHA384, SHA512)
4. **Module 4: Encryption Basics** — Caesar Cipher, ROT13, XOR Encryption
5. **Module 5: Decryption Basics** — Cryptanalysis, Caesar/ROT13/XOR Decryption

## Features
- Real-time scoring system with objective verification
- Hint penalty deduction (-20 pts per hint)
- Progress tracking and database synchronization
- Interactive Cryptography Suite & WebSocket Terminal
