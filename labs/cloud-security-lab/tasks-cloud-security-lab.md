# Standalone Tasks: Cloud Misconfiguration Lab

## Relevant Files
- `docker-compose.yml` - Multi-container setup for LocalStack, Backend, and Frontend.
- `backend/main.py` - FastAPI backend application for flag validation and rate limiting.
- `backend/requirements.txt` - Python dependencies for backend.
- `backend/seed.py` - Script to configure LocalStack AWS resources and generate flags.
- `frontend/` - Modern light-themed UI dashboard for the staged challenges.
