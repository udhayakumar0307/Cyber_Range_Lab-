- `cd` (Change Directory): Moves your active terminal context to a specified path. Critical for workstation navigation.
- `cat` (Concatenate & Print): Reads file contents and prints them directly to terminal standard output. Standard tool for inspecting configuration files and logs.

==================================================
Challenge Objective:
A web server log was flooded with duplicate entries during a system breach. Analyze log line counts, aggregate unique IP records, and extract the target access key.

Commands to Use:
- wc -l data/server.log
- sort data/server.log | uniq -c
- cut -d':' -f2 data/server.log
- grep -i "ACCESS_KEY" data/server.log

Step-by-Step Solution:
Step 1: Execute `wc -l data/server.log` to count total line records.

Step 3: Execute `cut -d':' -f2 data/server.log` to extract the key column.
Step 4: Execute `grep -i "ACCESS_KEY" data/server.log` to isolate the target line.

Command Explanations & Practical Use Cases:
- `wc -l` (Word Count - Lines): Counts total lines in text files. Essential for verifying dataset size and counting log entries.
- `sort`: Orders text lines alphabetically or numerically. Required before executing duplicate aggregation tools.
- `uniq -c`: Filters adjacent duplicate lines and prefixes line frequency counts. Critical in security incident response for identifying DDoS IP anomalies.
- `cut`: Extracts targeted columns or fields from delimited lines (`-d` delimiter, `-f` field index). Essential for parsing CSVs and log data.

Linux Module 4: Archive Extraction & Binary Inspection
==================================================
Challenge Objective:
An legacy backup archive contains encrypted binary blobs and encoded metadata. Decompress the tarball, inspect binary file types, extract printable ASCII strings, and decode base64.

Commands to Use:
- tar -xzf backup.tar.gz
- file extracted/*
- strings extracted/blob.dat
- echo "QUNDRVNTX0tFWTogRkxBR3tjbGxfbGludXhfbW9kdWxlNF9zdHVkZW50XzRiZDVhYTJkfQ==" | base64 -d

Step-by-Step Solution:
Step 1: Execute `tar -xzf backup.tar.gz` to extract the compressed archive.
Step 2: Execute `file extracted/*` to inspect file header signatures.
Step 3: Execute `strings extracted/blob.dat` to extract readable ASCII characters from binary blob.
Step 4: Pipe or pass extracted payload into `base64 -d` to decode the key payload.

Command Explanations & Practical Use Cases:
- `tar -xzf`: Extracts gzipped tarball archives (`-x` extract, `-z` gzip, `-f` file). Standard format for Linux software distribution.
- `file`: Determines real file types by inspecting magic byte headers rather than file extensions. Essential for malware analysis.
- `strings`: Scans binary executables/blobs and extracts printable ASCII strings of 4+ characters. Used in reverse engineering and forensics.
- `base64 -d`: Decodes Base64 encoded binary streams back to plain text bytes. Crucial in web security and email header decoding.
