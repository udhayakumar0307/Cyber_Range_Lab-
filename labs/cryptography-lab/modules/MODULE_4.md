# Module 4: Encryption Basics (Beginner Guided Training)

## Concept Overview
Explore symmetric encryption algorithms: Caesar Cipher, ROT13, and XOR Encryption.

## Guided Step-by-Step Objectives

### Objective 1: Encrypt Caesar
- **Goal**: Encrypt `HELLO` with Caesar shift 3.
- **Steps**:
  1. Input `HELLO`, select Caesar Cipher, shift `3`, click Encrypt.
- **Expected Output**: `KHOOR`
- **Flag**: `FLAG{khoor}`

### Objective 2: Encrypt ROT13
- **Goal**: Encrypt `SECRET` with ROT13.
- **Steps**:
  1. Input `SECRET`, select ROT13, click Encrypt.
- **Expected Output**: `FRPERG`
- **Flag**: `FLAG{frperg}`

### Objective 3: Encrypt XOR
- **Goal**: Encrypt `KEY` with XOR key `0x42`.
- **Steps**:
  1. Input `KEY`, select XOR Cipher, key `0x42`, click Encrypt.
- **Expected Output**: `092717`
- **Flag**: `FLAG{092717}`

### Objective 4: Encrypt Caesar Shift 5
- **Goal**: Encrypt `CRYPTO` with shift 5.
- **Steps**:
  1. Input `CRYPTO`, select Caesar Cipher, shift `5`, click Encrypt.
- **Expected Output**: `HXDUYT`
- **Flag**: `FLAG{hxduyt}`
