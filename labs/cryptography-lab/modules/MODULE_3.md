# Module 3: Hash Calculator (Beginner Guided Training)

## Concept Overview
Master computing message digests across MD5, SHA1, SHA224, SHA256, SHA384, and SHA512.

## Guided Step-by-Step Objectives

### Objective 1: Generate MD5
- **Goal**: Generate MD5 hash for `hello`.
- **Steps**:
  1. Input `hello` into Hash Calculator.
  2. Select `MD5` and compute digest.
- **Expected Output**: `5d41402abc4b2a76b9719d911017c592`
- **Flag**: `FLAG{5d41402abc4b2a76b9719d911017c592}`

### Objective 2: Generate SHA256
- **Goal**: Generate SHA256 hash for `hello`.
- **Steps**:
  1. Input `hello` into Hash Calculator.
  2. Select `SHA-256` and compute digest.
- **Expected Output**: `2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824`
- **Flag**: `FLAG{2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824}`

### Objective 3: Generate SHA512
- **Goal**: Generate SHA512 hash for `hello`.
- **Steps**:
  1. Input `hello` into Hash Calculator.
  2. Select `SHA-512` and compute digest.
- **Expected Output**: `9b71d224bd62f3785d96d46ad3ea3d73319bfbc2890caadae2dff72519673ca72323c3d99ba5c11d7c7acc6e14b8c5da0c45834ce32c50d4234fe193d2b80461`
- **Flag**: `FLAG{9b71d224bd62f3785d96d46ad3ea3d73319bfbc2890caadae2dff72519673ca72323c3d99ba5c11d7c7acc6e14b8c5da0c45834ce32c50d4234fe193d2b80461}`

### Objective 4: Target SHA256 Hash
- **Goal**: Compute SHA256 for `CryptoMaster2026`.
- **Steps**:
  1. Input `CryptoMaster2026` in Hash Calculator, compute SHA-256.
- **Expected Output**: `sha256_master_2026`
- **Flag**: `FLAG{sha256_master_2026}`
